# Rasa Chatbot

Chatbot developed using RASA, an open source machine learning tools for developers to build, improve, and deploy text-and voice-based chatbots and assistants.
It aims to provide information to people who want to obtain information about Università Politecnica delle Marche and processes related to enrolment, taxes and so on.

*This is a university project therefore it is in a embryonic state.*
